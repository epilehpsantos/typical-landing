It never guesses.

If a reply needs to know which listing or which client, Typical asks instead of inventing. Price and terms for what? It wants the answer before it writes.

It never reads your chats.

Typical is a keyboard extension. Apple's sandbox blocks any keyboard from reading other apps. It works from what you copy and what you type into it — nothing else. You review everything before it sends.
